# design-reference

Mockups aprovados do TapCal. **Nenhuma tela é construída sem o mockup dela aqui.**

Coloque nesta pasta as imagens exportadas (PNG ou JPG, largura de iPhone):

| Arquivo esperado     | Tela         | Usado na fase |
| -------------------- | ------------ | ------------- |
| `inicio.png`         | Início       | 3             |
| `alimentacao.png`    | Alimentação  | 3             |
| `scanner.png`        | Scanner      | 4             |
| `treino.png`         | Treino       | 3             |

Quando novas telas forem desenhadas (onboarding, paywall, caneta), os mockups
também entram aqui antes de qualquer código.

As cores e fontes dos mockups vivem em `src/theme/theme.ts`. Se um mockup mudar
uma cor, muda lá, em um lugar só.
